# EIF（外部インタフェース層）要件定義・設計・Frame実装

| フォルダ | 内容 |
|---|---|
| `00.共通/` | 要件定義（2026/10/20 合意版）、QA表、要件定義合意会議のカンペ |
| `01.通常版/設計/` | 仕様設計書（公開API。両版共通）、詳細設計書、EIF構成図、Frame／機種依存分離設計 |
| `01.通常版/実装/externalInterfaceLayer/` | 通常版（Frame／Connector／製品CFG）の実装と単体試験 |
| `02.ヘキサゴナル版/設計/` | ヘキサゴナルアーキテクチャ入門、設計書_ヘキサゴナル版、構成図（詳細関係図を含む） |
| `02.ヘキサゴナル版/実装/externalInterfaceLayer/` | ヘキサゴナル版（コア／ポート／アダプタ／組立て）の実装と試験 |
| `参考資料/` | 参照した既存リポジトリ・議事録（git管理対象外） |

## 2つの版の関係

- 公開API（`eif_api.h`）は両版で同じ。APIサーバー用のコード（通常版のConnector＝ヘキサゴナル版の使う側アダプタ）も同じ。
- 違いは公開APIの裏側の構造。比較は `02.ヘキサゴナル版/設計/設計書_ヘキサゴナル版.md` の14章を参照。

## 試験の実行

それぞれの実装フォルダで次を実行する（gccとPOSIXスレッドが必要。外部ヘッダーは既定で `参考資料/` を参照）。

```sh
sh build_and_test.sh
```

| 版 | 試験 | 結果（2026/10/22） |
|---|---|---|
| 通常版 | Frame 18件、MiniPrinter製品CFG 5件、依存規則とコンパイルの確認 | すべて成功 |
| ヘキサゴナル版 | コア 10件、コア＋MiniPrinterの通し試験 4件、依存規則とコンパイルの確認 | すべて成功 |
